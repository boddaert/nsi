# Exercices

## Exercice 1

Sans utiliser l'ordinateur et directement sur votre cahier, compléter les pointillés pour chacune des configurations suivantes :

1. Configuration 1

```python
>>> ma_variable = 56.01
>>> mystere = True
>>> mystere
...
```

2. Configuration 2

```python
>>> ma_variable = "hello world"
>>> mystere = ma_variable
>>> mystere
...
```

3. Configuration 3

```python
>>> ma_variable = 3
>>> mystere = ma_variable * ma_variable
>>> mystere
...
```

4. Configuration 4

```python
>>> mystere = 10
>>> mystere = mystere + 1
>>> mystere
...
```

5. Configuration 5

```python
>>> ma_variable = 20
>>> mystere = ma_variable + 20
>>> ma_variable = 30
>>> mystere = mystere + ma_variable
>>> mystere
...
```
